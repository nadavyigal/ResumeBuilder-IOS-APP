# WP-69 Story 1 + 2 — 1.4.7 physical device walk

**This record is unfilled. It requires hardware and cannot be produced by an agent or by a
simulator run.** The journey has failed on a physical device twice while reporting green in the
simulator, which is why the simulator does not substitute.

Install the **App Store** build (not TestFlight — TestFlight sets `isRunningFromTestFlight`,
which makes `resolveInternalTester` return `true` and suppresses the review prompt by design,

## Walk

Tick each step, and for any failure record what was on screen and what was expected.

- [ ] **1. Launch.** App opens to Home without a crash or a blank state.
- [ ] **2. Upload a résumé.** File picker opens, a PDF is selectable, and the file is accepted.
      Note whether the picker's Recents list is populated.
- [ ] **3. Add a job.** Paste a job description; validation accepts it.
- [ ] **4. Analyze.** Optimization starts and completes without the screen going blank.
- [ ] **5. Fit check.** Record the score shown.
- [ ] **6. Accept / Apply.** Apply the recommendations. **Record the score before and after —
      it must only climb.** This is the assertion the walk exists to make.
- [ ] **7. Expert pass.** Run it. Record the score again; again it must not fall.
- [ ] **8. Export.** Tap export, wait for the share sheet, then dismiss it.
      **→ Does the App Store rating prompt appear?  YES / NO**
      This single yes/no is WP-69 story 2. Record it even if every other step failed.
- [ ] **9. Relaunch.** Re-open the app and confirm the optimization is still there.
